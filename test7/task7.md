Треугольник Паскаля — бесконечная таблица биномиальных коэффициентов, имеющая треугольную форму. В этом треугольнике на вершине и по бокам стоят единицы. Каждое число равно сумме двух расположенных над ним чисел. Строки треугольника симметричны относительно вертикальной оси.

0:      1
1:     1 1
2:    1 2 1
3:   1 3 3 1
4:  1 4 6 4 1
Задание
Напишите в файле solution.js функцию generate(), которая возвращает указанную строку треугольника Паскаля в виде массива. Экспортируйте функцию по умолчанию.

Пример:

generate(0) // [1]
generate(1) // [1, 1]
generate(4) // [1, 4, 6, 4, 1]

Мой алгоритм решения:
Треугольник Паскаля состоит из рядов цифр (массивов). Каждый последующий ряд (строка) формируется на основе предыдущей. Ряд (строка) формируется путем сложения соседних цифр (предыдущего ряда), а потом с каждого края добавляются 1.
первый этап: написал функцию strTriangle([]) - которая формирует новый ряд [массив] на основе предыдущего ряда [массива]
второй этап: написал функцию generate (номер строки) - которая формирует треугольник (массив массивов)
и возвращает последний элемент массива, т.е. последний ряд.
